# Realtime Ticker and Live Price Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home, `/titulos` and `/t/[slug]` update by themselves (with a subtle flash) when any reign starts.

**Architecture:** `reigns` joins the `supabase_realtime` publication. A tiny client component subscribes to `postgres_changes` INSERT on `reigns` and calls `router.refresh()`, so the existing Server Components re-fetch through the existing services. A second tiny client component remounts a `<span>` with a CSS flash class when its `value` prop changes after the first render.

**Tech Stack:** Next.js 16.3 App Router, React 19.2, `@supabase/supabase-js` 2.112 (realtime-js), `@supabase/ssr` browser client, Tailwind v4 + `globals.css`, Postgres migration.

**Spec:** `docs/superpowers/specs/2026-10-12-realtime-design.md`

## Review Focus

- React StrictMode (on by default in App Router dev) runs the effect twice: `channel(topic)` returns the still-joined channel from the first run and `.on()` after `subscribe()` throws → the topic must be unique per effect run.
- Reconnect after a dropped socket: the first `SUBSCRIBED` must not refresh; a later one must (catch-up).
- `/t/[slug]` must not refresh when a *different* title is dethroned (filter `title_id=eq.<id>`).
- No flash on first load or on a plain navigation; flash only when the value changed under a mounted component.
- `prefers-reduced-motion`: `.live-flash` must not animate.

- [ ] **Step 4: Write `LiveRefresh`**

`src/components/live-refresh.tsx`:

```tsx
"use client";

import { useEffect } from "react";
import { useRouter } from "next/navigation";
import { REALTIME_SUBSCRIBE_STATES } from "@supabase/supabase-js";
import { createClient } from "@/lib/supabase/client";

// Re-renders the current route whenever a reign starts (only for one title when titleId is set).
export function LiveRefresh({ titleId }: { titleId?: string }) {
  const router = useRouter();

  useEffect(() => {
    const supabase = createClient();
    let joined = false;

    // Unique topic per run: StrictMode re-runs this effect before the previous channel finishes leaving.
    const channel = supabase
      .channel(`reigns:${titleId ?? "all"}:${crypto.randomUUID()}`)
      .on(
        "postgres_changes",
        {
          event: "INSERT",
          schema: "public",
          table: "reigns",
          ...(titleId ? { filter: `title_id=eq.${titleId}` } : {}),
        },
        () => router.refresh(),
      )
      .subscribe((status) => {
        if (status !== REALTIME_SUBSCRIBE_STATES.SUBSCRIBED) return;
        // A later SUBSCRIBED is a reconnect: catch up on what was missed while offline.
        if (joined) router.refresh();
        joined = true;
      });

    return () => {
      void supabase.removeChannel(channel);
    };
  }, [router, titleId]);

  return null;
}
```

- [ ] **Step 2: Write `LiveFlash`**

`src/components/live-flash.tsx`:

```tsx
"use client";

import { useState, type ReactNode } from "react";

interface LiveFlashProps {
  value: string | number | null;
  className?: string;
  children: ReactNode;
}

// Wraps live data and flashes it briefly whenever `value` changes after the first render.
export function LiveFlash({ value, className, children }: LiveFlashProps) {
  const [prev, setPrev] = useState(value);
  const [flashes, setFlashes] = useState(0);

  if (value !== prev) {
    setPrev(value);
    setFlashes(flashes + 1);
  }

  // A new key remounts the span, which restarts the CSS animation.
  return (
    <span key={flashes} className={flashes > 0 ? `live-flash ${className ?? ""}` : className}>
      {children}
    </span>
  );
}
```
